# Escape-Room

2024년, 고등학교 1학년 때 텍스트 코딩을 배우고 처음으로 만들어본 프로그램입니다.
완성은 2024년 1월 10일에 했는데 이제서야 올리게 되었습니다.

정보 과목 중 C언어를 배웠기 때문에 제출하는 언어도 C언어였습니다.
자율코딩이었는데 뭘 만들까 하다가 친구랑 방탈출을 주제로 얘기하던 게 떠올라서 만들게 되었습니다.



## 만들던 중 가장 크게 생겼던 문제는 컴파일러 문제였습니다.

학교에서 Dev-C++로 수업을 진행했어서 저도 자연스럽게 Dev-C++로 하려고 했었습니다.
근데 제 컴퓨터에서 Dev-C++이 컴파일이 안되길래, 인터넷 검색하면서 MingGW 설치하고 막 해봤는데 그래도 안돼서 결국 Code::Blocks를 썼습니다.
코딩을 이제야 막 시작했던 그 당시에 VS Code, Visual Studio 그런 거는 존재 자체를 몰랐습니다.

## 두 번째 문제는 '반복되는 부분을 어떻게 처리할 것이냐'였습니다.
코드를 쭉 길게 쓰기에는 아무것도 모르던 그때의 저한테도 너무 지저분해 보였습니다.
반복되는 부분들을 전부 다 그냥 작성하는 건 도저히 아니다 싶어서 생각을 해보던 중, 반복문 안에 조건문을 넣어서 그 안에 있는 조건문이 계속 반복되는 구조가 떠올랐습니다.

당시 저는 for문은 전체적인 구조를 반복시키는 데 쓰기에는 부적절하게 생겼다고 느껴서 while문을 사용했습니다.
그리고 가장 베이스가 되는 조건문을 작성해야 됐는데, 전부 다 if문만 쓰면 코드 가독성이 너무 못 봐줄 수준일 거 같아서 switch문으로 4개의 덩어리를 나누고, 세부적인 조건문을 if문으로 작성했습니다.


## 2년이 지난 뒤 지금 다시 이 코드를 보니 말도 안 나오게 스파게티입니다.
변수는 또 이게 실험용으로 만든 건지, 진짜 프로그램이랍시고 만든 건지 의심이 될 지경입니다.
이걸 만들 당시에도 '실무에서 이렇게 짜면 바로 잘리겠구나' 생각은 하면서 만들었었습니다. 다만 그때는 '그런 거 모르겠고 내가 재밌으면 그만'이라는 생각을 갖고 있었던 터라 그냥 계속 진행했었습니다.
